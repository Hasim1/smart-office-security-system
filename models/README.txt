Place the YOLO model file here.

Expected file:
    yolov8n.pt

How to get it (any one of these):
  1. Run:  python download_model.py        (downloads it into this folder)
  2. Or just run the app (python main.py) - it auto-downloads on first run.
  3. Or download manually from the Ultralytics releases and copy it here:
     https://github.com/ultralytics/assets/releases

The model path is set in config.py as:  MODEL_PATH = models/yolov8n.pt
